# 🐍 Akiba Development Journey — Week 5

## 🏗️ Python Object-Oriented Programming (OOP)

> 💡 **Learn → Practice → Build → Grow**

This week, I explored how Python uses **classes and objects** to organize code, model real-world entities, and build reusable, maintainable applications.

### 🎯 Learning Objectives

* 🧱 Understand classes, objects, attributes, and methods.
* 🔒 Learn encapsulation and abstraction to organize and protect data.
* ♻️ Use inheritance to reuse and extend existing code.
* 🎭 Apply polymorphism to give the same interface different behaviors.
* ⚙️ Explore properties, special methods, and dataclasses.
* 🧩 Understand composition and the basics of SOLID principles.
* 🏦 Apply OOP concepts in a mini bank account project.

### 📚 Topics Covered

* **Classes & Objects:** Create objects from classes and manage their data and behavior.
* **Constructors & `self`:** Initialize objects and access their attributes.
* **The Four Pillars of OOP:** Explore encapsulation, inheritance, polymorphism, and abstraction.
* **Methods & Properties:** Define object behavior and control access to attributes.
* **Special Methods:** Customize how objects behave with methods such as `__str__`, `__repr__`, and `__add__`.
* **Composition & Dataclasses:** Build flexible object relationships and simplify data-focused classes.
* **SOLID Principles:** Discover fundamental guidelines for writing maintainable object-oriented code.

### 🚀 Practical Work

Built OOP knowledge through class exercises, inheritance examples, method overriding, and a **Bank Account mini-project** using validation and encapsulation.

### 💡 Key Takeaway

**OOP brings data and behavior together**, helping me write Python code that is organized, reusable, and easier to maintain.

🌱 *One concept at a time, one project at a time, one step closer to becoming a better developer.*
