## 📚 Topics Covered

### 1. 🧱 Introduction to Functions

Learned how to define and call functions using `def`. Functions help organize code into named blocks, each designed to perform a specific task.

**Key takeaway:** A good function should have a clear purpose and be reusable whenever needed.

### 2. 📥 Parameters, Arguments & Return Values

Explored how functions receive information through parameters and arguments, process that information, and return results.

* **Parameters:** Variables defined in a function.
* **Arguments:** Actual values passed when calling a function.
* **`return`:** Sends a result back to the part of the program that called the function.
* **`print()`:** Displays information on the screen.

### 3. 🎛️ Function Arguments

Practiced different ways to pass information to functions.

* **Positional arguments:** Values are matched to parameters by their position.
* **Keyword arguments:** Values are assigned using parameter names.
* **Default parameters:** Provide default values when an argument is not supplied.
* **Multiple return values:** Return more than one result from a function.

### 4. 🔍 Local & Global Scope

Learned where variables can be accessed and how their scope affects program behavior.

* **Local variables:** Defined inside a function and generally accessible within that function.
* **Global variables:** Defined outside functions and accessible in appropriate scopes.

**Key takeaway:** Passing data explicitly between functions often makes programs easier to understand and maintain.

### 5. 🧩 Problem Decomposition

Discovered how to turn a large problem into smaller, manageable tasks, with each task handled by a separate function.

For example, a student management program could use individual functions to:

* Add a student.
* Calculate an average score.
* Determine pass or fail.
* Generate a student report.

### 6. ♻️ Reusable Functions & Refactoring

Practiced identifying repeated code and replacing it with reusable functions.

Refactoring improves existing code without changing its intended behavior, making it easier to read, test, debug, and maintain.

### 7. 🔗 Function Composition

Learned how one function can use the result of another function to complete a larger task.

**Example:** A billing function can call a calculation function to obtain the total before displaying the bill.

### 8. 🔄 Recursion

Explored how a function can call itself to solve a problem.

Two important parts of recursion are:

* **Base case:** Defines when the function should stop.
* **Recursive case:** Calls the function again with a smaller or simpler problem.

### 9. ⚡ Lambda Functions

Introduced short, anonymous functions written using the `lambda` keyword.

Lambda functions are useful for simple, single-expression operations, while regular functions are generally clearer for more complex logic.

## 💡 Key Lessons Learned

This week helped me understand that writing Python code is not just about making a program work. It is also about making the code understandable, reusable, and easier to improve.

My main takeaways:

* **One function, one clear responsibility.**
* Reuse functions instead of repeating the same code.
* Use parameters to make functions flexible.
* Use `return` when a result needs to be reused.
* Avoid unnecessary global variables.
* Break complex problems into smaller steps.
* Choose meaningful function names.
* Test functions individually before combining them.
