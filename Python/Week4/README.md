# 🐍 Akiba Development Journey — Week 4

## 🧠 Python Core: Mutability, References & Memory Model

### 🎯 Learning Objectives

By the end of this week, I aim to:

* Understand how Python objects, variables, and references work.
* Differentiate mutable and immutable objects.
* Understand object identity, aliasing, and copying.
* Explain how functions interact with objects and arguments.
* Explore how Python manages memory and removes unused objects.

### 📚 Topics Covered

#### 🔗 1. Objects & References

Learn how variables are names that refer to objects, and how assigning one variable to another can make both names refer to the same object.

#### 🔄 2. Mutability

Explore the difference between mutable objects, which can change in place, and immutable objects, which cannot be changed after creation.

#### 🪞 3. Aliasing & Identity

Understand how multiple variables can share one object, and learn the difference between `==` (value equality) and `is` (object identity).

#### 📋 4. Copying

Discover how shallow copying creates a new outer collection while potentially sharing nested objects, whereas deep copying recursively copies nested objects.

#### ⚙️ 5. Functions & Arguments

Learn how functions interact with mutable objects, distinguish mutation from parameter rebinding, and avoid bugs caused by mutable default arguments.

#### 🧹 6. Memory Management

Explore reference counting, garbage collection, and `del` to understand how Python manages object references and memory.

### 💡 Key Takeaway

**Assignment is not always copying!** Understanding how objects and references work helps me write safer, more predictable Python code.
