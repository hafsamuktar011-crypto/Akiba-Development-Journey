## 📚 Topics Covered

### 🔀 Conditions & Decision Making

Learned how programs make decisions using conditions and Boolean expressions.

Key concepts include:

* `if`, `elif`, and `else`
* Comparison operators
* Boolean values
* Logical operators: `and`, `or`, `not`
* Nested and multiple conditions
* Boundary cases and common conditional mistakes

Example:

```python
score = 75

if score >= 50:
    print("Pass")
else:
    print("Fail")
```

---

### 🔁 Loops & Repetition

Learned how to repeat a block of code instead of writing the same instructions multiple times.

Covered:

* `for` loops
* `while` loops
* `range()`
* `break`
* `continue`
* Counters and accumulators
* Nested loops
* Pattern printing

Example:

```python
for number in range(1, 6):
    print(number)
```

---

### 🧠 Computational Thinking & Problem Solving

A major focus of Week 2 was learning how to **think through a problem before writing the code**.

The process includes:

```text
Understand the problem
        ↓
Identify the input
        ↓
Identify the rules
        ↓
Break the problem into steps
        ↓
Write the code
        ↓
Test and debug
```

This helps turn a large problem into smaller and easier parts.

---

### 🔍 Manual Tracing & Debugging

Learned how to follow code step by step and understand what happens to variables during execution.

Manual tracing helps with:

* Predicting output
* Understanding loops
* Following changing variables
* Finding logic mistakes
* Understanding why a program behaves incorrectly

Debugging also focused on common problems such as incorrect conditions, indentation, loop conditions, and boundary cases.

## 🐛 Debugging & Logic

Week 2 also focused on understanding **why code does not behave as expected**.

Important debugging habits:

* Check the condition
* Check indentation
* Check the order of conditions
* Check loop conditions
* Check whether variables are changing correctly
