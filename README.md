# 🚀 Akiba Development Journey

Welcome to my **Akiba Development Journey**.

This repository documents my learning and growth throughout the **Akiba Technologies Software Engineering & Backend Bootcamp**.

It is a place where I keep track of what I learn, the practice I complete, the problems I solve, and the projects I build along the way.

---

## 📖 About This Journey

The Akiba Development Journey is a structured path toward becoming a stronger software engineer.

Throughout the program, I will be learning and practicing different areas of software development, starting with programming fundamentals and gradually moving toward data structures, backend development, APIs, databases, and production projects.

This repository will grow together with my skills.

---

## 🗺️ Learning Roadmap

The bootcamp is organized into four main phases:

| Phase | Focus |
|------|-------|
| 🐍 Phase 1 | Python, OOP & Foundational Data Structures |
| 🧠 Phase 2 | DSA Algorithms & Console Projects |
| ⚙️ Phase 3 | Backend Development & APIs |
| 🚀 Phase 4 | Team Capstone & Production Deployment |

Each phase builds on the knowledge from the previous one.
